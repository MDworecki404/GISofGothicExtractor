Format `G3V0` (sprawdzony): nagłówek `<6I3Q`: wersja, `b"G3V0"`, rewizja, szyfrowanie, kompresja, zarezerwowane, offset plików, offset katalogów, rozmiar. Pod offsetem katalogów leży korzeń. Wpis: 3×`u64` czasy, `u64` rozmiar, `u32` atrybuty. Katalog (`attr & 0x10`): napis nazwy, potem **dwie** listy: `u32 n` + n wpisów (podkatalogi), `u32 m` + m wpisów (pliki). Plik: `u64 offset, u64 rozmiar_spakowany, u64 rozmiar, u32 szyfrowanie, u32 kompresja`, napis nazwy (pełna ścieżka), napis komentarza. Napis: `u32 długość`, a gdy > 0, `długość + 1` bajtów (z zerem). Kompresja 2 i rozmiary różne → `zlib.decompress`.

### Task 2: Pliki `GENOMFLE` i obiekty właściwości

**Files:**
- Create: `tools/gothic_extract/g3/genome.py`
- Test: `tools/tests/test_g3_genome.py`

**Interfaces:**
- Consumes: `G3Fs.find`, `G3Fs.list`.
- Produces:
  - `class FormatError(Exception)`.
  - `class Reader`: `Reader(data: bytes, pos: int = 0)`, metody `u8/u16/u32/i32/f32() -> int|float`, `vec3() -> tuple[float, float, float]`, `guid() -> str | None`, `take(n: int) -> bytes`, pole `pos`.
  - `guid_str(raw16: bytes) -> str` — `"{" + str(uuid.UUID(bytes_le=raw16)) + "}"` (małe litery, jak w `.lrtpldatasc`).
  - `@dataclass GenomeFile(data: bytes, strings: list[str])`; `parse_genomfle(data: bytes) -> GenomeFile`.
  - `@dataclass Prop(name: str, type: str, raw: bytes, value: object)`.
  - `@dataclass PropertyObject(cls: str, class_version: int, props: dict[str, Prop], data_start: int, data_end: int)` — `data[data_start:data_end]` to dane własne klasy (po właściwościach).
  - `read_property_object(r: Reader, strings: list[str]) -> PropertyObject | None` — `None`, gdy flaga obecności = 0; po powrocie `r.pos == data_end`.
  - `decode_value(type_name: str, raw: bytes, strings: list[str]) -> object`.
  - `iter_property_objects(gf: GenomeFile) -> Iterator[PropertyObject]` (skan, opis w Step 4; pomocniczy do rozpoznania w Task 3).

Układ (sprawdzony na `.lrentdat` i `.tple`): plik `b"GENOMFLE"`, `u16 1`, `u32 offset tablicy napisów`. Tablica: `u32 0xDEADBEEF`, `u8 1`, `u32 n`, n × (`u16 len`, `len` bajtów latin-1). Obiekt: `u16 1` (wersja akcesora), `u8 jest`, gdy jest: `u16 1`, `u8 1`, `u16 klasa`, `u16 1`, `u8 0`, `u16 wersja`, `u16 wersja`, `u32 rozmiar` (liczony od następnego bajtu do `data_end`), `u16 30`, `u32 liczba właściwości`, właściwości (`u16 nazwa, u16 typ, u16 30, u32 rozmiar, dane`), dane klasy. Inna wartość pól stałych → `FormatError` z offsetem.

`decode_value`: `bool`/`char` → `raw[0]`; `short` → i16; `int`/`long` → i32; `float` → f32; typy z `String` w nazwie i rozmiarem 2 → `strings[u16]`; `bCVector` → 3×f32; `bCGuid` → `guid_str(raw[:16])` gdy `raw[16]`, inaczej `None`; `bTPropertyContainer<enum …>` → `u32` z `raw[2:6]`; `eCTemplateEntityProxy`/`eCEntityProxy` → GUID albo `None` (ustal w Step 3 na danych, test pilnuje). Inne typy → `raw`.
